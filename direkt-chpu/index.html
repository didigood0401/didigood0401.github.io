04

Метрика: цели, без которых Директ не учится

Автостратегии оптимизируются по целям. Если цели не настроены или считают мусор - кампания «учится» не на тех людях.

✓
Отправка заявки с чертежомключевая цель, по ней оптимизируется стратегия
✓
Клик по телефону и звонокtel-ссылки + коллтрекинг при необходимости
✓
Клик по WhatsApp / Telegram / emailотдельные JS-события на каждый канал
✓
Скачивание прайса и реквизитовмикроконверсия для B2B
✓
Составная цель «Лид»объединяет все обращения для отчётов

Опыт: Метрика с целями для платформы tr555.ru

Для клиента Олега, у которого реклама в Директе не давала результата, сделала лендинг раздела и настроила Метрику: 6 целей на JS-событиях (регистрация, вход, переходы к темам и материалам и др.), передача utm и yclid до основного сайта.

Цели созданы прямо в его счётчике, каждую проверила кликами на живом сайте - все 6 засчитываются в отчётах. Ключевая цель «успешная регистрация» готова для оптимизации кампаний в Директе.

Лендинг: tr555.ru/landing/scenario
